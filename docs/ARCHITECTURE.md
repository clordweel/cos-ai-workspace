## 数据流说明

### 1. 纯对话（无写库）

- 用户 → 前端 → 中间层 → **Dify** → 流式响应 → 中间层 **SSE** → 前端打字机展示。

### 2. 查询类（只读）

- 用户提问（如「球磨机零件库存」）→ Dify 识别意图 → 通过 **Dify 工具/API** 或 中间层 调用 **cos App 只读接口** → 结果经 Dify 或中间层格式化 → SSE 流式或结构化返回前端 → 以**任务卡片**等形式展示。

### 3. 写入类（需确认）

- 用户意图涉及创建/修改（如「根据模数、材质生成物料」）→ Dify 识别参数 → 中间层或 Dify 调用 cos **草稿/预检接口**（不直接写入）→ 返回「待确认」内容 → 前端展示确认卡片 → 用户确认后 → 中间层做**权限校验** → 再调用 cos **写入接口** → 结果流式或卡片反馈。

## 关键约束

- **前端不直连** Frappe/ERPNext，仅连中间层（及可选 Dify 前端直连仅用于简单对话，写入与敏感查询仍经中间层）。
- **所有 AI 对话** 在中间层侧统一走 **SSE**，保证打字机效果。
- **写入路径** 必须经过：意图识别 → 参数提取 → 确认/权限 → 再写入。
