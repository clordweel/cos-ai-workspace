## 数据流说明

### 1. 纯对话（无写库）

- 用户 → 前端 → 中间层 **聊天适配器**（mock / matrix 等）→ 流式响应 → 中间层 **SSE** → 前端打字机展示。适配器可对接 Dify 或其它后端。

### 2. 查询类（只读）

- 用户提问（如「球磨机零件库存」）→ 经适配器或编排识别意图 → 中间层调用 **cos App 只读接口** → 结果经中间层格式化 → SSE 流式或结构化返回前端 → 以**任务卡片**等形式展示。

### 3. 写入类（需确认）

- 用户意图涉及创建/修改（如「根据模数、材质生成物料」）→ 中间层或适配器识别参数 → 调用 cos **草稿/预检接口**（不直接写入）→ 返回「待确认」内容 → 前端展示确认卡片 → 用户确认后 → 中间层做**权限校验** → 再调用 cos **写入接口** → 结果流式或卡片反馈。

## 关键约束

- **前端不直连** Frappe/ERPNext/Dify，仅连中间层；认证唯一入口为 **Logto**（前端可承载登录/回调页）。
- **所有 AI 对话** 经中间层**聊天适配器**统一走 **SSE**，保证打字机效果。
- **写入路径** 必须经过：意图识别 → 参数提取 → 确认/权限 → 再写入。
